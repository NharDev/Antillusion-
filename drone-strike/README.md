# DRONE STRIKE — ضربة الدرون

لعبة درون بمنظور الشخص الأول (FPV) بتتلعب بيد PlayStation. طير بين المباني لحد ما تصيب الهدف، ولو لمست أي حاجة تانية الدرون هينفجر.

## التشغيل
1. وصّل يد PS4 أو PS5 بالكمبيوتر (USB أو Bluetooth).
2. افتح `index.html` في Chrome أو Edge. مش محتاج تسطيب ولا سيرفر ولا إنترنت.
3. دوس أي زرار في اليد، وبعدها **✕** عشان تبدأ. ممكن تدوس F11 عشان تلعب بملء الشاشة.

## التحكم
| | يد PlayStation | الكيبورد |
|---|---|---|
| طلوع / نزول | العصا الشمال ↕ | Space / Shift |
| لف يمين وشمال | العصا الشمال ↔ | Q / E |
| قدام / ورا | العصا اليمين ↕ | W / S |
| حركة جانبية | العصا اليمين ↔ | A / D |
| تسريع / فرامل | R2 / L2 | F / V |
| زاوية الكاميرا | L1 / R1 | [ / ] |
| تأكيد · رجوع · إعادة | ✕ · ○ · □ | Enter · Backspace · R |
| إيقاف مؤقت | OPTIONS | Esc / P |

## المراحل
المراحل مالهاش آخر، وكل مرحلة بتتولّد تلقائيًا وأصعب من اللي قبلها:
- المدينة بتكبر، والشوارع بتضيق، والمباني بتعلى، والسقف المسموح للطيران بينزل.
- الهدف بيبعد وبيصغر، ووقت البطارية بيقل.
- مخاطر جديدة بتظهر بالتدريج:
  - المرحلة 2: أعمدة إنارة
  - المرحلة 3: درونات دورية
  - المرحلة 4: رياح
  - المرحلة 5: كابلات وأزقة ضيقة
  - المرحلة 6: الهدف بيتحرك
  - المرحلة 8: شفرات دوّارة
- الجو بيتغير مع المراحل: نهار، بعده غروب، بعده ضباب، بعده ليل. وفي المراحل المتقدمة علامة الهدف ما بتظهرش غير لما تقرّب منه.

أي لمسة لمبنى أو للأرض أو لكابل أو لعمود أو لدرون أو لشفرة معناها انفجار، وكمان لو البطارية خلصت. تقدّمك وأحسن أوقاتك بيتحفظوا في المتصفح.
