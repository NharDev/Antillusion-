# نموذجك الخاص لـ Antillusion

كل ما هنا يعمل بنماذج مفتوحة الأوزان (رخصة Apache-2.0): تنزّل الملف، تعدّل عليه، تدرّبه، وتشغّله على جهازك أو سيرفرك. لا مفتاح API ولا اشتراك ولا حدّ طلبات.

## المرحلة 1 — جرّب اليوم على جهازك (مجاناً)

كرتك RTX 4060 (8 GB) يشغّل نموذج 7 مليار وزن. يصلح للتجربة والمهام الصغيرة، وهو أضعف من النماذج الكبيرة.

```bash
ollama pull qwen2.5-coder:7b
ollama create antillusion-coder -f Modelfile
```

ثم في Antillusion: **Settings ← مصدر النماذج ← Ollama على هذا الجهاز**، واختر `antillusion-coder` من قائمة النماذج.

## المرحلة 2 — نموذج قوي على GPU مستأجر

| النموذج | الحجم | الذاكرة المطلوبة تقريباً |
|---|---|---|
| `Qwen/Qwen3-Coder-30B-A3B-Instruct` | 30 مليار | بطاقة 48 GB |
| `Qwen/Qwen3-Coder-Next` | 80 مليار | 2 × 48 GB أو أكثر |

على السيرفر:

```bash
API_KEY=ضع-قيمة-طويلة-عشوائية bash serve.sh
```

في Antillusion: **مصدر النماذج ← سيرفري السحابي**، اكتب `http://IP-السيرفر:8000/v1`، وضع قيمة `API_KEY` في خانة المفتاح.

أطفئ السيرفر عندما لا تعمل: الإيجار بالساعة.

## المرحلة 3 — درّبه على عملك أنت

1. استعمل Antillusion كالعادة. كل محادثة انتهت بنجاح تدخل تلقائياً، ويمكنك تعليم محادثة «ناجحة» أو استبعادها من قائمة ⋮ أعلى المحادثة.
2. **Settings ← بيانات التدريب ← تصدير JSONL**.
3. على السيرفر:

```bash
pip install -r requirements.txt
python train_lora.py --data antillusion-train.jsonl --out out/antillusion-lora
LORA=out/antillusion-lora API_KEY=... bash serve.sh
```

يظهر نموذجك في التطبيق باسم `antillusion`.

## ما تتوقعه

- بضع محادثات لا تغيّر شيئاً يُذكر؛ الأثر يبدأ من مئات المحادثات الجيدة. قبل ذلك أضف بيانات برمجة عامة مفتوحة الترخيص بنفس الصيغة عبر `--extra`.
- لا تدرّب على مخرجات نماذج مغلقة (Opus، GPT): شروطها تمنع ذلك في الغالب.
- ملف التصدير يحتوي كودك ومحادثاتك؛ لا ترفعه إلى مكان عام.
- `serve.sh` و`train_lora.py` مكتوبان ولم يُشغَّلا على GPU بعد. أول تشغيل قد يحتاج ضبط `TOOL_PARSER` (جرّب `hermes` إن رُفض `qwen3_coder`).
